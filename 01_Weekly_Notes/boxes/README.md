# Box Write-Ups

One file per rooted machine, created from `03_Templates/Box_Template.md`.

Name files like `PG-Shenzi.md` or `HTB-BoardLight.md`. Fill the template *while* you work the box — enumeration, foothold, shell stabilization, privilege escalation, flags — and always finish the 2-sentence Lesson if you were stuck over 3 hours.
